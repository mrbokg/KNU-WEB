# ТЗ: лендинг мерча КНУ «Коллекция 1925»

Дата: 2026-11-03 · Сдача: 2026-11-04 · Репозиторий: `mrbokg/KNU-WEB`

## 1. Цель

Одностраничный продающий сайт на **WordPress** для мерча Кыргызского национального университета им. Ж. Баласагына. На сайте можно выбрать товар, цвет и размер и оформить заказ. Это учебный проект, который показывают преподавателям по ссылке и сопровождают презентацией `.pptx`.

Требования к результату:

- работает публичная ссылка на WordPress-сайт;
- на лендинге оформляется заказ, и он появляется в админке WordPress;
- есть переключатель языков RU/KG;
- адаптив проверен на ширине 375 px, 768 px и 1440 px;
- готова презентация.

## 4. Структура лендинга

1. **Плашка-анонс:** «Коллекция 1925 — к 100-летию КНУ · Самовывоз в КНУ бесплатно».
2. **Шапка:** логотип, якорные ссылки (Коллекция, Размеры, Доставка, FAQ), переключатель RU/KG, иконка корзины со счётчиком. При прокрутке шапка закрепляется.
3. **Hero:** заголовок (RU «Носи КНУ. С 1925 года.» / KG «КУУну кий. 1925-жылдан бери.»), подзаголовок, мокап двойки, кнопки «Заказать» и «Смотреть коллекцию».
4. **Коллекция (2 двойки):** у каждой карточки
   - галерея, которую меняют свотчи цвета;
   - название и цена, перечёркнутая цена «по отдельности» и бейдж экономии;
   - выбор размера кнопками;
   - кнопка «В корзину»;
   - раскрывающийся состав и уход.
5. **Аксессуары:** три компактные карточки с кнопкой «В корзину» (у кепки есть выбор цвета).
6. **Детали:** 4 пункта (хлопок 80%, плотность 320 г/м², вышивка вместо печати, свободный крой), тонкие линейные иконки (SVG).
7. **Таблица размеров:** XS–XXL; обхват груди, длина изделия, длина рукава, обхват бёдер (см).
8. **Как заказать:** 3 шага (выбери, оформи, забери).
9. **Доставка и оплата:**
   - самовывоз бесплатно: КНУ, ул. Фрунзе 547, Бишкек;
   - доставка по Бишкеку 150 сом;
   - по регионам КР 300 сом;
   - оплата через MBank, O!Деньги или наличными при получении.
10. **FAQ:** 5–6 вопросов (сроки, обмен размера, оплата, опт для факультетов, вышивка).
11. **Футер:** логотип, контакты, соцсети КНУ (Instagram @knu_j.balasagyn, Telegram t.me/KNUJusupBalasagyn), пометка «Учебный проект».
12. **Мобильная версия:** внизу закреплена кнопка «Корзина · N товаров · сумма», если в корзине что-то есть, иначе «Заказать».

## 5. Заказ

1. «В корзину» добавляет позицию (товар, цвет, размер, количество) в корзину в `localStorage`.
2. Корзина открывается боковой панелью: можно менять количество и удалять позиции, видна сумма.
3. Кнопка «Оформить» открывает форму: имя\*, телефон\* (маска +996), способ получения\* (самовывоз / Бишкек / регионы), адрес (если не самовывоз), комментарий.
4. Форма отправляет `POST /wp-json/knu/v1/orders` с WP nonce и honeypot-полем. Сервер:
   - проверяет поля;
   - **пересчитывает цены из данных товаров**, суммам из браузера не доверяет;
   - создаёт запись `knu_order`;
   - возвращает номер вида `KNU-0001`.
5. Покупатель видит экран успеха: номер заказа, сумма, кнопки «Написать в WhatsApp» и «Написать в Telegram» с готовым текстом заказа. Корзина очищается.
6. Ошибки: ошибки валидации подсвечиваются в форме. При ошибке сети показывается сообщение и та же кнопка WhatsApp как запасной канал.

## 6. Админка WordPress

- **Товары** (`knu_product`): заголовок RU/KG, описание RU/KG, цена, цена «по отдельности», цвета (название RU/KG и HEX), размеры, фото на каждый цвет, бейдж, порядок.
- **Заказы** (`knu_order`, не публичный): колонки с номером, клиентом, телефоном, суммой, статусом («Новый», «Подтверждён», «Выдан», «Отменён») и датой. Статус меняется в карточке заказа.
- **Настройки темы** (Внешний вид → Настройки КНУ): номер WhatsApp (заглушка `+996 700 000 000`), Telegram-ник, текст плашки.
- При активации тема сама создаёт товары и страницу-главную (seed), поэтому сайт полный сразу после установки.

## 7. Языки

- Язык выбирается параметром `?lang=ru|kg`, выбор запоминается в cookie. По умолчанию RU. У `<html>` выставляется `lang="ru"` или `lang="ky"`.
- Строки интерфейса лежат в `lang/ru.php` и `lang/kg.php`, тексты товаров берутся из полей RU/KG.
- Плагины (Polylang и т. п.) не используются.

## 8. Техническое решение

Своя классическая тема без конструкторов страниц и без jQuery на фронте.

```
theme/knu-merch/
  style.css, functions.php, front-page.php, header.php, footer.php, index.php
  inc/  cpt-products.php, cpt-orders.php, rest-orders.php, i18n.php, settings.php, seed.php
  template-parts/  section-hero.php, section-collection.php, section-accessories.php,
                   section-details.php, section-sizes.php, section-steps.php,
                   section-delivery.php, section-faq.php
  lang/  ru.php, kg.php
  assets/  css/main.css, js/cart.js, js/main.js, img/ (логотип, мокапы, иконки)
docker-compose.yml   # локальный WordPress + MySQL, тема примонтирована
blueprint.json       # WordPress Playground
presentation/        # .pptx и скриншоты
docs/                # ТЗ и план
```

- **Мокапы.** Фото базовых изделий (худи, свитшот, джоггеры, кепка, кружка) берутся из источников со свободной лицензией (Unsplash/Pexels) или делаются как PNG с перекраской. Логотип накладывается скриптом (Node + sharp). На выходе готовые WebP по каждому цвету в `assets/img/products/`.
- **Производительность.** Изображения в WebP и `loading="lazy"`, шрифты Google Fonts с `display=swap`, CSS и JS по одному файлу без сборщика.
- **Доступность.** Свотчи и размеры сделаны радиокнопками с подписями, панель корзины закрывается по Esc и держит фокус внутри, контраст текста не ниже AA.

## 9. Хостинг и доступ

1. **Основной вариант: WordPress Playground.** Файл `blueprint.json` в репо ставит тему из GitHub, активирует её, создаёт товары и включает нужные постоянные ссылки. Ссылка `https://playground.wordpress.net/?blueprint-url=<raw-ссылка на blueprint.json>`.
   - Для этого репо `KNU-WEB` нужно сделать **публичным**. Сделаем это только после подтверждения.
   - Минусы: загрузка 10–30 секунд, данные (в том числе заказы) сбрасываются при каждом открытии.
2. **Запасной вариант: бесплатный PHP-хостинг** (InfinityFree или аналог). Аккаунт регистрирует владелец проекта. Я готовлю ZIP темы и инструкцию по установке. Получаем постоянный адрес, заказы сохраняются.
3. **Локально:** `docker compose up`, сайт открывается на `http://localhost:8080`. Используется для разработки и скриншотов.
