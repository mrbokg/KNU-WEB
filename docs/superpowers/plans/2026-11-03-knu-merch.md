# KNU Merch «Коллекция 1925» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Цель:** WordPress-тема `knu-merch`, одностраничный лендинг мерча КНУ: корзина, оформление заказа через REST, заказы в админке, языки RU/KG, демо через WordPress Playground.

**Архитектура:** классическая тема. Товары — CPT `knu_product`, его засевает `inc/data-products.php`. Заказы — CPT `knu_order`, создаются через `POST /wp-json/knu/v1/orders`. Фронт без сборщика: один `main.css` и два JS-файла. Данные в JS передаются через `window.KNU`.

**Стек:** WordPress 6.x, PHP 8.x, ванильный JS (ES2020), CSS custom properties, Google Fonts (Montserrat, Inter), WordPress Playground (CLI для разработки, blueprint для демо), Node + sharp для мокапов.

Спека: `docs/superpowers/specs/2026-11-03-knu-merch-design.md`.

### C2. PHP API (реализует Backend, использует Frontend)

```php
knu_lang(): string                 // 'ru' | 'kg'. Источник: ?lang=, затем cookie knu_lang, иначе 'ru'
knu_t(string $key): string         // строка из lang/{lang}.php; если нет — берётся из ru.php, если нет и там — сам $key
knu_e(string $key): void           // echo esc_html(knu_t($key))
knu_lang_url(string $lang): string // текущий URL с ?lang=$lang
knu_setting(string $key): string   // 'whatsapp' (только цифры, напр. '996700000000'), 'telegram' (ник без @),
                                   // 'announce_ru', 'announce_kg'
knu_get_products(?string $type = null): array // локализованные товары из CPT, отсортированы по menu_order
knu_img(string $file): string      // URL файла get_theme_file_uri('assets/img/products/' . $file)
knu_money(int $som): string        // '4 900 сом' (RU) / '4 900 сом' (KG), неразрывный пробел для тысяч
```

Структура элемента `knu_get_products()`:

```php
[
  'id' => 12, 'slug' => 'set-hoodie', 'type' => 'set',       // 'set' | 'accessory'
  'title' => 'Двойка «Худи + джоггеры»', 'desc' => '...', 'composition' => '...',
  'badge' => 'Хит',                                          // '' если нет
  'price' => 4900, 'price_separate' => 5300,                 // price_separate = 0 если нет
  'sizes' => ['XS','S','M','L','XL','XXL'],                  // [] если нет размеров
  'colors' => [
    ['key' => 'grey', 'hex' => '#B9B9B6', 'name' => 'Серый меланж',
     'images' => ['https://…/set-hoodie-grey-1.webp', 'https://…/set-hoodie-grey-2.webp']],
  ],
]
```

### C3. `window.KNU` (формирует Backend в `inc/assets.php`, читает Frontend JS)

```js
window.KNU = {
  rest: "https://…/wp-json/knu/v1/orders",
  nonce: "…",                       // wp_create_nonce('wp_rest'), заголовок X-WP-Nonce
  lang: "ru",
  products: { "set-hoodie": { title, type, price, price_separate, sizes: [...],
              colors: { grey: { name, hex, images: [...] } } } },
  delivery: { pickup: 0, bishkek: 150, regions: 300 },
  contact: { whatsapp: "996700000000", telegram: "knu_merch" },
  i18n: { /* все ключи из lang/{lang}.php, начинающиеся с "js." */ }
};
```

Скрипты: `knu-cart` → `assets/js/cart.js`, `knu-main` → `assets/js/main.js` (зависит от `knu-cart`), оба в футере, `KNU` выводится inline перед `knu-cart`. Стили: `knu-fonts` (Google Fonts: Montserrat 600;700, Inter 400;500;600, `display=swap`, кириллица) и `knu-main` → `assets/css/main.css`.

### C4. REST `POST /wp-json/knu/v1/orders`

Запрос (JSON):
```json
{ "name": "Айбек", "phone": "+996 700 123 456", "delivery": "pickup",
  "address": "", "comment": "", "lang": "ru", "website": "",
  "items": [ { "slug": "set-hoodie", "color": "navy", "size": "M", "qty": 1 } ] }
```
Правила: `name` 2–60 символов; в `phone` 9–15 цифр; `delivery` ∈ pickup|bishkek|regions; `address` обязателен, если delivery ≠ pickup; в `items` от 1 до 20 позиций; `qty` 1–10; `slug`, `color`, `size` должны существовать у товара (`size` пустая строка, если у товара нет размеров); `website` (honeypot) должен быть пустым, иначе ответ 200 `{ok:true, number:"KNU-0000"}` без сохранения. Цены сервер считает сам.

Ответ 201:
```json
{ "ok": true, "number": "KNU-0007", "subtotal": 4900, "delivery_fee": 0, "total": 4900,
  "items": [ { "title": "Двойка «Худи + джоггеры»", "color": "Тёмно-синий", "size": "M", "qty": 1, "price": 4900, "sum": 4900 } ] }
```
Ответ 400 (стандартная ошибка WP_Error):
```json
{ "code": "knu_invalid", "message": "Проверьте поля формы", "data": { "status": 400, "fields": { "phone": "Введите номер телефона" } } }
```
Номер заказа: `KNU-` + 4-значный счётчик из option `knu_order_seq`.

### C5. Корзина (Frontend, `localStorage`)

Ключ `knu_cart_v1`: `[{ slug, color, size, qty }]`. Одинаковые slug, color и size объединяются в одну позицию.

### C6. Изображения (Mockups → Frontend)

- `assets/img/logo.png`: цветной логотип с прозрачным фоном, около 512 px.
- `assets/img/logo-white.png`, `assets/img/logo-blue.png`: одноцветные версии.
- `assets/img/hero.webp`: 1600×1200, двойка flat-lay или на модели, фон `#F5F5F3`.
- `assets/img/products/{slug}-{color}-{n}.webp`: 1200×1500 (4:5), фон `#F5F5F3`.
  - Двойки: n = 1 (худи или свитшот крупно), n = 2 (комплект целиком).
  - Аксессуары: только n = 1.
  - Slug и цвета: `set-hoodie` и `set-sweatshirt` × grey/navy/black; `cap` × navy/black; `mug` × white; `keychain` × blue.

Frontend обязан корректно показывать карточку, пока картинок нет (фон `#F5F5F3`, без битых иконок).

### C7. Языковые файлы

`lang/ru.php` и `lang/kg.php` содержат `return [ 'key' => 'строка', … ];` с плоскими ключами через точку (`hero.title`, `js.cart.empty`). Набор ключей в обоих файлах одинаковый.
