# Image credits

## KNU logo

- `logo.png`, `logo-white.png`, `logo-blue.png` and the logo on every product image come from the official logo of Jusup Balasagyn Kyrgyz National University.
- Source: https://www.knu.kg/ky/ru/wp-content/uploads/sites/2/2024/02/logo_knu_new_810_fin.png (PNG 809×809).
- Rights holder: Kyrgyz National University. Used here only for a university merch project.
- One-colour versions: ink is computed from each pixel's distance from white. Blue parts are fully opaque, yellow parts are lighter (about 55%), and white becomes transparent.

## Product mockups and hero

- `hero.webp` and `products/*.webp` contain **no third-party photos**.
- Every garment and accessory (hoodie, crewneck sweatshirt, joggers, cap, mug, keychain) is drawn procedurally as layered SVG in `tools/mockups/build.mjs` and rasterised with [sharp](https://sharp.pixelplumbing.com/) (Apache-2.0).
- Fabric grain, melange, rib knit, folds, stitching and shadows are all generated by the script.
- Font in the joggers text «КНУ · 1925» is a system font: Montserrat if installed, otherwise Segoe UI or Arial.

## Regenerate

```
cd tools/mockups
npm install
# put the logo PNG from the URL above into tools/mockups/_downloads/logo_knu.png
node build.mjs              # all images
node build.mjs --only=cap   # a subset by name
```
